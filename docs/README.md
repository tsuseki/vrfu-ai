# Documentation

The browsable index. This file is also rendered inside the website at the **📖 Docs** tab.

This project is designed to be operated through an LLM agent — most of these docs are written for the agent first (with a human-readable structure on top). The agent's entry point is [`../CLAUDE.md`](../CLAUDE.md) at the repo root.

| Doc | Read this when… |
|---|---|
| [install.md](install.md) | First-time setup; downloading the base SDXL checkpoint; troubleshooting installation |
| [quickstart.md](quickstart.md) | You just installed and want to run a friend's LoRA right now |
| [add-character.md](add-character.md) | You have reference images of your own character and want to train a LoRA |
| [queue.md](queue.md) | Building queue entries (you or an agent) — API recipe, close-up rule, preference-learning loop |
| [exporting.md](exporting.md) | Bundling a character LoRA + config to send to a friend, or unpacking one you received |
| [prompting.md](prompting.md) | Writing prompts for Illustrious / NoobAI / SDXL anime models |
| [artist-palette.md](artist-palette.md) | Curated artist tags that work well on these models |
| [reference.md](reference.md) | Folder layout, config schemas, web API — power-user reference |
| [troubleshooting.md](troubleshooting.md) | Something's broken at runtime (incl. Blackwell-specific issues) |

The website navigates these via the 📖 Docs tab — pick a doc on the left, content renders on the right.
